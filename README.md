# 송파구 필지 데이터 뷰어

송파구 연속지적도, 토지 정보, 건축물대장 데이터를 활용한 지도 기반 필지 데이터 뷰어입니다.

## 주요 기능

- 전체 화면 지도
- VWorld WMTS 배경지도, API 키가 없으면 OpenStreetMap 대체 표시
- 송파구 필지 경계 표시
- 건축물 주용도별 필지 색상 구분
- 주용도별 필터와 투명도 조절
- 필지 클릭 시 팝업 및 우측 상세 패널 표시
- 송파구 전체 필지 수, 면적, 건물 수, 주용도별 통계 표시

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 아래 주소를 엽니다.

```text
http://localhost:5173
```

## 환경 변수

`.env.example`을 참고하여 `.env` 파일을 만들고 VWorld API 키를 설정할 수 있습니다.

```text
VITE_VWORLD_API_KEY=YOUR_VWORLD_API_KEY
```

API 키가 없으면 OpenStreetMap 배경지도를 사용합니다.

## 데이터 전처리

현재 프로젝트의 원본 데이터로 GeoJSON을 다시 생성하려면 아래 명령을 실행합니다.

```bash
npm run preprocess
```

생성되는 파일:

- `public/data/parcels.geojson`
- `public/data/boundaries.geojson`

## GitHub Pages 배포

`main` 브랜치에 push하면 GitHub Actions가 `npm run build`를 실행하고 `dist`를 GitHub Pages에 배포합니다.

VWorld API 키를 배포 환경에서도 사용하려면 GitHub 저장소의 Actions Secret에 아래 이름으로 등록합니다.

```text
VITE_VWORLD_API_KEY
```

## 2. 각 부분별 추가 사항

### 서론

서론의 문제의식은 유효하다. 다만 위례를 “실패 사례”로 단정하기보다는 “자족기능 형성이 지연된 비교 사례”로 표현하는 편이 안전하다. 공실률·분양 지연·기업 유치 부진 관련 근거는 참고문헌에 실제 기사명, 발행일, URL을 넣어야 한다. 현재 본문에는 조선일보, 한국경제, LH 정산 보고서가 언급되어 있으나 참고문헌 형식으로 정리되어 있지 않다.

### 분석 방법

방법론은 대체로 적절하다. 보고서에는 시스템 화면과 코드 산출물의 연결을 명시하면 좋다.

- 토지이용: 시스템 1.1, 1.3 화면 / `metrics.json`, `pangyo_landuse.geojson`, `wirye_landuse.geojson`
- 건축물·개발 실현: 시스템 1.2, 1.4 화면 / `pangyo_buildings.geojson`, `wirye_buildings.geojson`
- 교통망: 시스템 2.1~2.5 화면 / `iso22_summary.json`, `iso22_accessibility.json`, `cumulative_accessibility.json`, `station_area_ratio.json`
- 인구사회: 시스템 3.1, 3.2 화면 / `population_household_summary.json`, `worker_business_summary.json`

특히 3.1.4는 아래 문장으로 교체하는 것을 권장한다.

> 평균 용적률은 판교 310.3%, 위례 414.2%로 위례가 더 높게 나타났다. 그러나 총 연면적은 판교 2,710,137㎡, 위례 482,530㎡이며, 경계 대비 연면적 비율은 판교 407.3%, 위례 68.3%로 큰 차이를 보인다. 이는 위례의 일부 건축물은 높은 용적률로 개발되었지만, 업무·상업 후보지 전체 차원의 개발 실현 규모는 판교에 크게 미치지 못한다는 뜻이다. 따라서 업무지구 성공 여부는 개별 건축물의 용적률보다 구역 전체의 연면적 축적, 업무시설 비중, 종사자 밀도와 함께 판단해야 한다.

## 3. 4장 성공요인 도출 작성안

## 4. 성공요인 도출

본 분석에서 판교테크노밸리는 위례 업무·상업용지보다 업무지구로서 더 높은 성과를 보였다. 성공 여부를 단순히 특정 지표 하나로 판단하기는 어렵지만, 토지이용, 교통망, 인구사회 지표를 종합하면 판교의 성공요인은 크게 네 가지로 정리할 수 있다.

### 4.1 업무 기능의 명확한 특화와 연면적 집적

첫 번째 성공요인은 업무 기능의 명확한 특화와 실제 연면적 집적이다. 판교는 토지이용계획상 도시지원시설용지가 전체의 71.1%를 차지하며, 토지이용 혼합도는 0.509로 위례의 0.836보다 낮다. 이는 판교가 여러 기능을 고르게 섞은 복합지구라기보다 업무·산업 기능에 집중된 특화형 업무지구로 조성되었음을 의미한다.

건축물 기준에서도 같은 경향이 확인된다. 판교의 총 연면적은 2,710,137㎡로 위례의 482,530㎡보다 약 5.6배 크다. 업무시설 연면적 비율도 판교 63.9%, 위례 44.8%로 판교가 높다. 위례는 토지이용 혼합도와 평균 용적률은 높지만, 구역 전체에 실제로 축적된 업무 연면적은 판교보다 훨씬 작다. 따라서 업무지구의 성공에는 용도지역 지정 자체보다 업무 기능을 수용할 충분한 연면적과 기능적 특화가 중요하다고 볼 수 있다.

### 4.2 실제 일자리 밀도와 직주비의 압도적 차이

두 번째 성공요인은 실제 일자리의 집적이다. 100m 격자 기반 분석에서 판교의 사업체 수는 2,325개, 위례는 1,253개로 판교가 약 1.9배 많다. 차이는 종사자 수에서 더 크게 나타난다. 판교의 종사자 수는 80,812명인 반면 위례는 4,918명으로, 판교가 약 16.4배 많다.

밀도 지표에서도 판교의 우위가 분명하다. 사업체 밀도는 판교 3,497.1개/㎢, 위례 1,774.8개/㎢이며, 종사자 밀도는 판교 121,552.5명/㎢, 위례 6,966.2명/㎢이다. 직주비 역시 판교 129.30, 위례 1.61로 큰 차이를 보인다. 이는 판교가 단순히 주거지 내부의 상업공간이 아니라 외부에서 대규모 노동력이 유입되는 고용 중심지로 작동하고 있음을 보여준다. 업무지구의 성공을 판단할 때 가장 직접적인 지표는 토지이용계획보다 실제 종사자 밀도와 직주비라고 할 수 있다.

### 4.3 광역 교통 접근성과 역세권 내 업무공간 집중

세 번째 성공요인은 광역 교통 접근성과 역세권 내 공간 집중이다. 30분 등시간권에서는 위례 복정역이 99개 역에 도달 가능해 판교역의 80개보다 많다. 그러나 60분 등시간권에서는 판교역 349개, 복정역 330개로 판교가 우세하다. 등시간권 면적도 판교 2,165.3㎢, 위례 1,817.8㎢로 판교가 더 넓다.

도달가능 인구·종사자에서도 판교는 광역권에서 강점을 보인다. 60분 기준 판교는 총인구 9,615,674명, 총종사자 5,820,325명에 접근 가능한 반면, 위례는 총인구 9,287,410명, 총종사자 5,755,491명이다. 30분권에서는 위례가 우세하지만, 45분 이후부터 판교의 접근성 증가 폭이 커지고 60분 기준에서는 판교가 더 넓은 광역 인구·일자리 시장과 연결된다.

역세권 면적 비율도 중요하다. 판교는 핵심역 1.5km 반경에 분석 구역의 85.92%, 2km 반경에 100.0%가 포함된다. 반면 위례는 1.5km 55.05%, 2km 62.27%에 그친다. 면적가중 평균거리도 판교 1,120.7m, 위례 1,465.2m로 판교가 더 짧다. 즉 판교는 업무공간이 핵심역 주변에 압축적으로 배치되어 대중교통 접근성이 실제 업무공간 이용성과 연결되는 구조를 갖는다.

### 4.4 주거 중심 복합성보다 고용 중심 자족성이 중요

네 번째 성공요인은 복합성보다 고용 중심 자족성이 우선된다는 점이다. 위례는 구역 내 인구 3,065명, 가구 1,564가구로 판교의 인구 625명, 가구 537가구보다 많다. 토지이용 혼합도 역시 위례가 높다. 하지만 이러한 주거·상업 복합성은 높은 업무 성과로 이어지지 않았다. 위례의 종사자 수와 종사자 밀도는 판교에 비해 매우 낮고, 직주비도 1.61에 머문다.

따라서 업무지구의 성공은 단순한 복합개발이나 상주인구 확보만으로 설명되지 않는다. 주거 기능은 생활권 형성에는 도움이 되지만, 업무지구의 성공을 위해서는 기업 입지, 업무 연면적, 광역 교통, 실제 종사자 유입이 함께 작동해야 한다. 판교는 이 네 요소가 결합된 사례이고, 위례는 계획상 업무·상업용지가 존재하지만 실제 고용 중심성은 충분히 형성되지 않은 사례로 해석할 수 있다.

## 4. 5장 분석의 한계 작성안

## 5. 분석의 한계

본 분석은 공공데이터와 직접 구축한 웹 시스템을 이용해 두 업무지구를 정량적으로 비교했다는 점에서 의의가 있다. 그러나 분석 결과를 해석할 때 다음 한계를 고려해야 한다.

### 5.1 데이터 한계

첫째, 데이터의 기준연도가 완전히 일치하지 않는다. 토지이용계획도는 2026년 5월 기준, GIS 건물통합정보는 2026년 6월 기준, 지하철 네트워크는 2026년 5월 기준, SGIS 인구·가구·사업체·종사자 격자는 2023년 기준 자료를 사용했다. 따라서 도시공간의 최신 상태와 인구사회 지표 사이에는 시간차가 존재한다.

둘째, 업무지구의 성공 또는 실패를 직접 보여주는 공실률, 임대료, 기업 매출, 업종별 기업 명부, 통근 OD 자료는 포함하지 못했다. 본 보고서는 종사자 수, 사업체 수, 업무시설 연면적, 직주비를 활용해 업무 기능의 실현 정도를 간접적으로 판단했다. 따라서 “위례가 실패했다”는 인과적 결론보다는 “현재 확보한 공공데이터 기준으로 판교보다 업무 기능 집적이 약하다”는 진단으로 해석해야 한다.

셋째, GIS 건물통합정보의 속성값에는 결측 또는 0값이 존재한다. 용적률은 원자료의 `A18` 값을 우선 사용하고, 값이 비어 있을 때 `연면적(A14) / 대지면적(A15) × 100`으로 보완했다. 이 과정은 개별 건물 단위의 개발 강도를 비교하는 데 유용하지만, 건물별 대지면적 결측과 경계 교차 건물 포함 기준에 따라 평균값이 달라질 수 있다.

넷째, 위례 분석 구역은 전체 신도시가 아니라 토지이용계획도에서 업무·상업 기능을 수행할 수 있는 용지를 선별한 후보 경계이다. 따라서 위례 전체 도시의 성과가 아니라 “위례 내 업무·상업 후보지”의 성과로 한정해 해석해야 한다.

### 5.2 방법론 한계

첫째, 본 분석은 상관관계와 공간적 차이를 보여줄 수 있지만 인과관계를 확정하지는 못한다. 판교의 높은 종사자 밀도와 광역 접근성이 성공과 관련되어 있다는 점은 확인할 수 있으나, 어느 요인이 어느 정도의 인과효과를 냈는지는 별도의 계량모형이나 시계열 자료가 필요하다.

둘째, 공간단위 통합 과정에서 경계효과와 MAUP 문제가 발생할 수 있다. 건물은 분석 경계와 일부라도 교차하면 포함했고, 필지는 중심점 기준, 집계구는 중심점 기준, 100m 격자는 50% 이상 중첩 기준을 사용했다. 이 기준은 각 데이터의 성격에 맞춘 실용적 선택이지만, 경계 부근의 건물·격자 포함 여부에 따라 일부 지표가 달라질 수 있다.

셋째, 등시간권은 실제 보행권이나 도로망 기반 접근권이 아니다. 지하철 네트워크에서 30분·60분 이내 도달 가능한 역을 산출한 뒤, 각 역 주변 500m 버퍼 외곽점을 convex hull로 묶어 근사했다. 따라서 실제 보행 접근성, 버스 연계, 역 출입구 위치, 환승 혼잡, 배차 변동성은 반영하지 못했다.

넷째, 직주비는 구역 내 종사자 수를 구역 내 상주인구로 나눈 단순 지표이다. 이 값은 업무 중심성을 직관적으로 보여주지만, 실제 통근자의 거주지, 통근 방향, 낮시간 체류인구를 직접 측정한 것은 아니다. 특히 판교처럼 상주인구가 매우 적은 업무지구에서는 직주비가 크게 나타날 수 있으므로, 종사자 수와 종사자 밀도와 함께 해석해야 한다.

다섯째, 판교와 위례는 조성 목적, 입지, 개발 시기, 산업 유치 정책이 서로 다르다. 본 보고서는 두 지역을 업무·상업용지라는 공통 기준으로 비교했지만, 제도적 지원과 민간 투자 환경의 차이를 완전히 통제하지 못했다. 따라서 분석 결과는 “성공요인의 후보를 도출하는 비교 분석”으로 보는 것이 적절하다.
